## 演習1：数値とリスト

`ml02_1.py` に次の3つの関数を実装してください。

### `divide(a, b)`

数値 `a` と `b` を受け取り、`a / b`、`a // b`、`a % b` をこの順にタプルで返します。

条件：`b` は0ではありません。

```python
divide(7, 2)
# 戻り値: (3.5, 3, 1)
```

### `pick_values(values)`

リスト `values` の先頭の値、末尾の値、先頭2要素のリストを、この順にタプルで返します。

条件：`values` は2要素以上のリストです。

```python
pick_values([21.5, 19.8, 22.1, 20.6])
# 戻り値: (21.5, 20.6, [21.5, 19.8])
```

### `count_at_least(values, threshold)`

数値のリスト `values` のうち、`threshold` 以上の要素数を整数で返します。`threshold` と等しい値も数えます。

`values` が空の場合は `0` を返します。

```python
count_at_least([21.5, 19.8, 22.1, 20.6], 20.5)
# 戻り値: 3
```

## 演習2：文字列から特徴量へ

`ml02_2.py` に次の3つの関数を実装してください。

`to_features` と `count_labels` の引数 `lines` は、文字列のリストです。各文字列はカンマで区切った「数値,数値,ラベル」の形式で、先頭2項目は `float` に変換できます。

### `to_features(lines)`

各文字列の先頭2項目を `float` に変換し、2要素のリストにします。これらを入力と同じ順序で並べた二重リストを返します。ラベルは戻り値に含めません。

`lines` が空の場合は `[]` を返します。

```python
to_features(["5.1,3.5,setosa", "6.2,3.4,virginica"])
# 戻り値: [[5.1, 3.5], [6.2, 3.4]]
```

### `count_labels(lines)`

各文字列の3項目目をラベルとして数え、ラベルをキー、件数を整数の値とする辞書を返します。キーの順序は問いません。

`lines` が空の場合は `{}` を返します。

```python
count_labels(["5.1,3.5,setosa", "6.2,3.4,virginica", "4.9,3.0,setosa"])
# 戻り値: {"setosa": 2, "virginica": 1}
```

### `column_stats(features, j)`

数値の二重リスト `features` から、列番号 `j` の平均値、最大値、最小値を求め、この順にタプルで返します。列番号は0から数えます。

条件：`features` は1行以上あり、各行の列数は同じです。`j` は存在する列を指定します。

```python
column_stats([[5.1, 3.5], [6.2, 3.4]], 0)
# 戻り値: (5.65, 6.2, 5.1)
```

浮動小数点計算による微小な丸め誤差は許容します。
